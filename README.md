# TABULA SORTIUM

An experimental browser-based divination table by MAJYUTSUDO.

## Website

The GitHub Pages site will serve `index.html` from the repository's `main` branch at the root.

## Local use and privacy

Reading data and settings are stored in each user's own browser (`localStorage`), not in this GitHub repository. They may be lost when the browser's site data is cleared or when using a different device/browser. This is an experimental version; please avoid relying on local storage as permanent archival storage.
