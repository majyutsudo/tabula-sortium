# TABULA LENORMAND — built-in artwork assets

This directory holds **L01.webp** through **L36.webp**, one 1024×1536 full-face illustration per card. They are generated from the approved 36-card print composites and are referenced by `js/lenormand.js`.

Upload the 36 WebP files from the companion ZIP **to this directory**, preserving these exact file names. Do not add the ZIP itself here: browsers cannot render a file directly out of a ZIP archive. Keep original artwork and the separate frame master outside this public artwork directory.

Card IDs: `lenormand-01` through `lenormand-36`. The 28th and 29th images must be the revised Gentleman/Lady compositions, not the previous originals.
